# 剪贴板保留内联嵌入并保持媒体隔离

复制、剪切、粘贴和拖放到光标走同一套契约：保留正文文字、已支持的基础排版，以及作为实体的内联嵌入；继续剔除正文媒体与分割线。提及带走 id、sign、displayText；频道引用带走 id、displayText；表情只带走 emoji id，图片 URL 不进剪贴板也不进文档。

TeamGaga 编辑器之间靠系统剪贴板上我们自己的 HTML 往返。提及/频道引用用 blot DOM（`span.tgg-mention` / `span.tgg-channel` 及 data 属性，文本为 `@displayText` / `#displayText`）。表情复制为 `<span class="tgg-emoji" data-emoji-id="…">:id:</span>`：无 `<img>`、无 `src`、无 `data-emoji-missing`。`text/plain` 只是给人读的降级：`@${displayText}`、`#${displayText}`、`:${emojiId}:`。纯文本和外源 HTML 都不推断成内联嵌入。被剔除的媒体和分割线不留占位符。

粘贴只检查形状，不检查实体是否仍有效。未注册的 emoji id 仍作为表情实体留下，按缺失渲染。有 id 但没有 displayText 的提及/频道引用整颗丢弃；sign 缺失或不合法时缺省为 `!`；缺 id 但有 displayText 的降为普通文字。

剪贴板不是搬正文媒体的工具。同一文档内剪切带图的选区再粘贴，图从原处删除且不会回来。要搬图，用宿主选择器再插一次。

这保持既有媒体隔离（剪贴板不是绕过宿主选择器的上传通道，见 ADR-0005），同时让用户在同一文档内和跨编辑器挪段落时，三个内联嵌入仍是可交互的实体。

## Considered Options

- **只保外观、不保实体 id**（否决）：贴回来的 `@Alice` 不再是提及。
- **纯文本粘贴时用正则把 `@`、`#`、`:emoji:` 升格为嵌入**（否决）：纯文本没有实体 id 和 sign。
- **放开正文媒体，或仅放行「自家 HTML」里的图**（否决）：无法与外源 HTML 区分，除非加签名；签名会被备忘录丢掉。剪切丢图是有意缺口。
- **剪切遇到媒体就拒绝**（否决）：图不会丢，但也挪不走，还要另做一套交互。
- **被剔除的图留下 `[图片]` 或空标签**（否决）：占位会变成真正文，还要 i18n。
- **粘贴时向宿主校验 id / 给嵌入加签名**（否决）：剪贴板绑上成员列表；跨编辑器往返失败。
- **未注册表情降成 `:id:` 或丢弃**（否决）：粘贴时毁掉实体。
- **没 displayText 时用 id 当显示名**（否决）：内部标识露到正文。
- **表情复制带 `<img src>` 或空壳 span**（否决）：泄漏本地/blob 路径，或让外部应用看到空白。

## Consequences

- 系统剪贴板上的 HTML 可能被备忘录等应用优先取用；表情对外显示为 `:id:` 文本，不再是图片。
- 伪造的 `tgg-mention` HTML 可以写入文档。通知会不会发出去，由发送路径决定，不由剪贴板决定。
- 从 Circle 贴到没有该表情包的 IM，文档里仍是表情实体，渲染为空位，直到注册表有这个 id。
