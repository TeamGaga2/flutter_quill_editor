# 剪贴板保留正文分隔线并维持媒体隔离

复制、剪切、粘贴和拖放到光标放行正文分隔线（`<hr class="tgg-divider">` 与 `{ insert: { divider: "true" } }`），与内联嵌入（提及、频道引用、表情）及基础排版文字共同走剪贴板往返；正文媒体（图片、视频）继续剔除并维持既有媒体隔离。

TeamGaga 编辑器之间靠系统剪贴板上的 HTML 往返：

- 复制与剪切：`text/html` 保留 `<hr class="tgg-divider">`，不被 `rewriteCopyHtml` 剥离；`text/plain` 给人读降级为 `---\n`。剪切带正文分隔线的选区时，原处正文分隔线被删除，剪贴板带走正文分隔线并在粘贴时能完整还原。
- 粘贴与拖放：`stripPasteHtml` 放行 `<hr>` 节点；Quill Blot 认领所有标准 HTML `<hr>`（含外源 `<hr>` 及带有 `tgg-divider` 类名的自产 `<hr>`），转为 `{ insert: { divider: "true" } }` 顶层内容块。`stripEmbeds` 白名单放行 `{ divider: "true" }`。
- 纯文本契约保持不变：纯文本中的 `---` 或 `***` 不推断升格为正文分隔线实体，仅作为普通文本粘贴。

正文分隔线是纯结构排版元素，无外部媒体资源加载、无本地路径泄漏风险、无业务 ID 鉴权依赖，因此与正文媒体的隔离策略解耦。

## Considered Options

- **严格仅认领带有 `class="tgg-divider"` 的 `<hr>`**（否决）：`<hr>` 为标准 HTML 语义元素，外源富文本粘贴时丢弃无类名 `<hr>` 会破坏常规排版体验。
- **纯文本粘贴 `---` 正则升格为分隔线**（否决）：与 ADR-0006“纯文本只给人读、不推断升格为实体”的原则冲突，会误伤代码块或 Markdown 草稿。
- **纯文本降级为空或单换行**（否决）：无法向外部纯文本接收方（如终端、备忘录）传达水平分隔意图，Markdown 风格的 `---` 是人读降级最自然的形式。
- **将分隔线与图片一起放行**（否决）：图片涉及宿主选择器、上传凭证与本地缓存等媒体隔离边界（见 ADR-0005），分隔线不带资源载荷，两者所有权与生命周期不同。

## Consequences

- 同一文档内或跨 TeamGaga 编辑器挪动包含分隔线的段落时，正文分隔线能够正确保留并往返。
- 从网页或第三方富文本编辑器复制带有 `<hr>` 的内容粘贴到编辑器时，会自动转换为 TeamGaga 的正文分隔线顶层内容块。
- 正文媒体（图片、视频）继续维持剔除策略，剪切带图选区依然丢图，媒体隔离边界不受影响。
